CORE SERVICES:

1. QuranService.js
- Fetch 114 Surahs
- Fetch Ayahs
- Search Surah/Ayah
- Cache responses
API: https://api.alquran.cloud/api

2. PrayerService.js
- Prayer times (Fajr, Dhuhr, Asr, Maghrib, Isha)
- Next prayer countdown
- Monthly timetable
API: https://api.aladhan.com/v1/timingsByCity

3. QiblaService.js
- Compass-based Qibla direction
- GPS location detection
- Distance to Makkah
API: https://api.aladhan.com/v1/qibla
